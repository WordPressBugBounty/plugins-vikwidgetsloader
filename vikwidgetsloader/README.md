## VikWidgetsLoader
A simple plugin used to load several widgets at once.

### Plugins currently supported:

* Category Post
* Content Slider _(discontinued: still bundled for existing sites, but no longer registered/offered for new use — see `vikwl_discontinued_widgets()` in `libraries/functions.php`)_
* Cookies Policy
* Google Maps
* Grid Content
* Icons
* Speakers
* Text Slide
* TripAdvisor Review
* Counter
* Custom Text

_Developed by [VikWP](https://vikwp.com)_
